# Prixa

**Prixa** is a free Windows image viewer that recovers corrupted files, by MonoZero.

 [Website](https://prixaa.vercel.app) ·  [Download v1.0.0](https://github.com/Mono-Zero/Prixa/releases/download/v1.0/Prixa.exe)

## What it does

- **Opens almost anything:** PNG, JPEG, WebP, AVIF, TIFF, BMP, GIF, ICO, and RAW camera formats
- **Recovers corrupted files:** four fallback methods to salvage broken images instead of crashing
- **Built-in converter:** export to PNG, JPEG, BMP, TIFF, WebP, or ICO in one click
- **Lightweight:** smart preview loading keeps RAM use low

## Requirements

Windows 10 or 11.
